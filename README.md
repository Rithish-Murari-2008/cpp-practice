# C++ Practice

A beginner-friendly repository for learning C++ through small programs, exercises, and notes. This repository records my learning as I go.

## Getting started

You need a C++17-compatible compiler such as GCC, Clang, or a recent version of MSVC.

Compile the example from the repository root:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic examples/hello-world.cpp -o hello-world
./hello-world
```

On Windows, run the produced `hello-world.exe` from your terminal.

## Repository structure

- `examples/` — small complete programs
- `fundamentals/` — language basics
- `functions-arrays-strings/` — practice as these topics are learned
- `stl/` — examples using the Standard Template Library
- `practice-log.md` — progress and lessons learned

- [ ] Input, output, variables, and types
